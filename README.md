# xdll

Téléchargeur et bibliothèque de médias (X, YouTube, Instagram, Pinterest) pour Windows.

Ce dépôt ne contient que les [releases](https://github.com/Sutsikii/xdll/releases) : l'installateur et les mises à jour automatiques de l'app. Le code source est privé.

**Installer :** télécharger `xdll.Setup.x.y.z.exe` dans la [dernière release](https://github.com/Sutsikii/xdll/releases/latest).
